# Instituto Prevencionista

Site institucional em Next.js + TypeScript + Tailwind, preparado para deploy na Vercel.

Para o guia completo de configuração (planilhas do Google, e-mail automático, variáveis de
ambiente, deploy), veja [README-PT.md](./README-PT.md).

## Rodando localmente

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
